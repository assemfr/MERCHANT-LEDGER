# دفتر التاجر المحلي

تطبيق ويب تقدمي (PWA) عربي RTL مع واجهة إنجليزية. يمكن إنشاء عدة دفاتر متاجر منفصلة على الجهاز نفسه، ويحفظ كل دفتر محلياً في متصفح الجهاز. **لا توجد حسابات أو قاعدة بيانات سحابية أو مزامنة تلقائية، ولا يتصل التطبيق بخادم لتخزين السجلات.**

## التثبيت على iPhone وAndroid

التطبيق مُعدّ كتطبيق ويب قابل للتثبيت (PWA) على النظامين. لا تحتاج نسخة Android إلى APK لتثبيته بهذه الطريقة، ولا تُعدّ هذه النسخة ملف iOS أصلياً من App Store. يجب أولاً نشر ملفات الواجهة على رابط HTTPS وفتح الرابط مرة واحدة مع توفر الإنترنت.

- **iPhone:** افتح الرابط في Safari، ثم اضغط «مشاركة» ← «إضافة إلى الشاشة الرئيسية» ← «إضافة». افتح الدفتر بعد ذلك من الأيقونة الجديدة.
- **Android:** افتح الرابط في Chrome، ثم قائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»، ثم افتحه من الأيقونة.
- بعد التحميل الأول، ملفات الواجهة مخزنة للاستخدام دون اتصال. أول فتح وتثبيت يحتاجان اتصالاً.
- سجلات كل جهاز تبقى مستقلة. لن تنتقل بين iPhone وAndroid تلقائياً؛ انقلها يدوياً بنسخة احتياطية مشفّرة أو عادية من كل دفتر.
- هذه الحزمة لا تُنشئ APK أو IPA أصلياً. إنشاء APK مستقل أو تطبيق iOS لمتجر التطبيقات يتطلبان إعداد بناء وتوقيع منفصلين.

## نشر الواجهة على GitHub Pages

ملفات الموقع موجودة في `public/`، ومسارها النسبي يدعم رابط GitHub Pages الخاص بالمستودع (مثل `https://username.github.io/repository/`). يوجد سير عمل جاهز في `.github/workflows/deploy-pages.yml` ينشر مجلد `public/` عند الدفع إلى فرع `main`، أو عند تشغيله يدوياً من تبويب Actions.

1. ارفع ملفات المشروع إلى مستودع GitHub، مع مجلدي `public/` و`.github/`.
2. استخدم الفرع `main`، أو عدّل اسم الفرع في ملف سير العمل إذا كان فرعك مختلفاً.
3. من إعدادات المستودع افتح **Pages**، واجعل **Build and deployment** على **GitHub Actions**.
4. ادفع التغييرات إلى `main`، ثم انتظر نجاح مهمة **Deploy local ledger PWA** في تبويب **Actions**.
5. افتح رابط Pages الذي يظهر في إعدادات Pages، ثم ثبّت التطبيق على iPhone أو Android وفق الخطوات أعلاه.

GitHub Pages يستضيف ملفات التطبيق العلنية فقط، وليس سجلات المستخدم. لا تضف مفاتيح أو معلومات خاصة إلى ملفات الموقع. لا يحتوي هذا المشروع على API أو قاعدة بيانات سجلات.

## تجربة محلية

من مجلد المشروع:

```bash
python3 server.py
```

ثم افتح `http://localhost:8080`. هذا الأمر يشغّل المعاينة من مجلد التطبيق. عمليات الدفتر تحفظ داخل مساحة تخزين المتصفح على الجهاز.

## أين تُحفظ البيانات؟

- IndexedDB هو التخزين الأساسي، مع `localStorage` كبديل إذا لم يتوفر.
- البيانات مرتبطة بهذا المتصفح/التثبيت والجهاز؛ لا تنتقل تلقائياً إلى هاتف أو حاسوب آخر.
- لا تشفّر قاعدة البيانات المحلية تلقائياً. احمِ الجهاز بقفل شاشة، ولا تمسح بيانات المتصفح قبل أخذ نسخة احتياطية.
- خذ نسخة JSON عادية أو مشفرة بكلمة مرور، وخزّنها خارج الجهاز. النقل إلى جهاز آخر يدوي: تصدير النسخة ثم استيرادها.
- بيانات المتصفح ليست نسخة احتياطية؛ حذف بيانات التطبيق أو المتصفح أو فقد الجهاز قد يؤدي إلى فقدها.

## الوظائف

- الصفقات والدفعات الجزئية والديون ومواعيد الاستحقاق.
- الإصلاحات والحرف، الخزينة والسندات، التقارير وكشوف الحساب والطباعة.
- كتالوج يدوي للسلع والخدمات؛ الكميات لا تتغير تلقائياً عند تسجيل صفقة.
- سجلات الحيوان والرعاية والأرض والفلاحة وتصنيفات قابلة للتخصيص.
- CSV وJSON، استيراد صيغة الدفتر القديم، ونسخ احتياطية محلية مشفرة بكلمة مرور.
- العربية والإنجليزية، واجهة مناسبة للهاتف، ودليل تجارة توعوي غير ملزم.

## الاختبار

```bash
python3 -m unittest discover -s tests -v
node --check public/app.js
node --check public/pages.js
node --check public/main.js
node tests/ui-qa.cjs
```

اختبار الواجهة يتطلب تشغيل المعاينة المحلية على المنفذ 8080، ويتحقق من عدم إرسال السجلات عبر الشبكة.

## حدود هذا النمط

- يمكن إنشاء دفاتر متعددة على الجهاز نفسه، لكن لا توجد مشاركة فريق أو مزامنة بينها وبين أجهزة أخرى.
- كل نسخة احتياطية تخص دفتر المتجر المفتوح فقط؛ صدّر نسخة لكل دفتر، وعند الاستيراد افتح الدفتر المقصود أولاً.
- تذكيرات WhatsApp تفتح تطبيقاً أو رابطاً خارجياً، ولذلك تحتاج اتصالاً عند الإرسال؛ لا يلزم ذلك لإدخال السجلات أو عرضها أو حفظها.
- نسخة PWA تحتاج تنزيل ملفاتها أول مرة قبل العمل دون اتصال. تثبيت التطبيق على iPhone أو Android يحتاج رابط HTTPS عاماً؛ معاينة Arena ليست رابط تثبيت عاماً.
- لم يُختبر التثبيت والعمل دون اتصال على جهاز iPhone أو Android فعلي.
- لا تستخدم هذه النسخة التجريبية بديلاً عن فاتورة قانونية أو نظام محاسبي/ضريبي معتمد.
