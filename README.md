# دفتر التاجر المحلي — Merchant Ledger

إصدار الصيانة **1.3.1** (هيكل PWA cache **v12**) المبني على واجهة v1.3/v11. تطبيق محلي يعمل دون اتصال ويحفظ كل دفتر على الجهاز الحالي؛ لا توجد مزامنة سحابية.

## تشغيل ونشر الويب
- افتح [دليل GitHub Pages بالعربية](GITHUB_PAGES_AR.md) للنشر المجاني.
- للاختبار محلياً: `python3 -m http.server 8080` ثم افتح `http://localhost:8080` في المتصفح. يلزم HTTPS (أو localhost) لتثبيت PWA وبعض ميزات المشاركة.
- ارفع رقم الكاش في أول `sw.js` عند كل إصدار جديد كي تصل الملفات المحدّثة إلى الأجهزة.

## Capacitor
يتضمن المشروع إعداد Capacitor. حدّد `appId` الفعلي في `capacitor.config.json` قبل بناء تطبيق متجر، ثم شغّل `npm install` و`npm run build:web` و`npx cap sync`. يبني السكربت مجلد `www/` من ملفات هذا المجلد.

## بياناتك
كل دفتر محلي ومستقل، وتفضيل المظهر محفوظ لكل دفتر. خذ نسخة احتياطية يدوياً بانتظام وقبل نقل البيانات أو مسح المتصفح. رمز القفل الاختياري لا يشفّر قاعدة البيانات. راجع `privacy.html` واستبدل عنوان التواصل التجريبي قبل النشر العام.

## الوظائف المضمونة في هذه الحزمة
تبديل الوضع الفاتح/الداكن لكل دفتر، حذف آمن للعناصر التجريبية الموسومة فقط عبر جميع المجموعات، المخزون اليدوي/التلقائي، قفل اختياري، دليل المعاملات وحاسبات الزكاة، والنسخ والمشاركة عبر واجهة الويب أو جسر Capacitor.
